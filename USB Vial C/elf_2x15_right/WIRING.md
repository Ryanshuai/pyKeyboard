## GPIO 接线表

### 行线 (2根，蛇形穿过)

| GPIO | 逻辑行 | 连接的键 (物理) |
|------|--------|----------------|
| GP1  | Row0   | K0,K1,K2 / K6,K7,K8 / K12,K13,K14 / K18,K19,K20 / K24,K25,K26 (左半边) |
| GP2  | Row1   | K3,K4,K5 / K9,K10,K11 / K15,K16,K17 / K21,K22,K23 / K27,K28,K29 (右半边) |

### 列线 (15根，每根连2键)

| GPIO | 逻辑列 | 连接的键 |
|------|--------|----------|
| GP3  | Col0   | K0 ══ K3 |
| GP4  | Col3   | K6 ══ K9 |
| GP5  | Col6   | K12 ══ K15 |
| GP6  | Col9   | K18 ══ K21 |
| GP7  | Col12  | K24 ══ K27 |
| GP8  | Col1   | K1 ══ K4 |
| GP9  | Col4   | K7 ══ K10 |
| GP10 | Col7   | K13 ══ K16 |
| GP11 | Col10  | K19 ══ K22 |
| GP12 | Col13  | K25 ══ K28 |
| GP13 | Col2   | K2 ══ K5 |
| GP14 | Col5   | K8 ══ K11 |
| GP15 | Col8   | K14 ══ K17 |
| GP16 | Col11  | K20 ══ K23 |
| GP17 | Col14  | K26 ══ K29 |

### 线性键 (6根，共地)

| GPIO | 位置 | 功能 |
|------|------|------|
| GP23 | 里侧 | MO(1) Fn层 |
| GP22 |      | Ctrl |
| GP21 |      | Alt |
| GP20 |      | GUI/Win |
| GP19 |      | Shift |
| GP18 | 外侧 | Ctrl+F8 |

**线性键另一脚全部接 GND**
