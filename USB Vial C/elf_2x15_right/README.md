# Elf 键盘 - 2×15 矩阵版本

## GPIO 分配（共 23 个）

| 用途 | GPIO | 数量 |
|------|------|------|
| 矩阵行 | GP0, GP1 | 2 |
| 矩阵列 | GP2 - GP16 | 15 |
| 线性键 | GP17 - GP22 | 6 |
| **总计** | | **23** |

## 布线方式

### 物理布局 → 逻辑矩阵

```
物理布局（5行×6列 = 30键）：

        物理列: 0   1   2 │ 3   4   5
                ← 左半边 → │ ← 右半边 →
                          │
物理行0:       [K0] [K1] [K2] │ [K3] [K4] [K5]
物理行1:       [K6] [K7] [K8] │ [K9] [K10][K11]
物理行2:       [K12][K13][K14]│ [K15][K16][K17]
物理行3:       [K18][K19][K20]│ [K21][K22][K23]
物理行4:       [K24][K25][K26]│ [K27][K28][K29]
```

### 行线走法（只有 2 根！）

```
Row0 (GP0)：蛇形穿过所有左半边
  K0 → K1 → K2 ↓
  K8 ← K7 ← K6 ↓
  K12→ K13→ K14↓
  K20← K19← K18↓
  K24→ K25→ K26
  
Row1 (GP1)：蛇形穿过所有右半边
  K3 → K4 → K5 ↓
  K11← K10← K9 ↓
  K15→ K16→ K17↓
  K23← K22← K21↓
  K27→ K28→ K29
```

### 列线走法（15 根，每根只连 2 个键）

```
Col0  (GP2):  K0 ←→ K3   (物理行0，相邻！)
Col1  (GP3):  K1 ←→ K4   (物理行0，相邻！)
Col2  (GP4):  K2 ←→ K5   (物理行0，相邻！)
Col3  (GP5):  K6 ←→ K9   (物理行1)
Col4  (GP6):  K7 ←→ K10  (物理行1)
Col5  (GP7):  K8 ←→ K11  (物理行1)
Col6  (GP8):  K12←→ K15  (物理行2)
Col7  (GP9):  K13←→ K16  (物理行2)
Col8  (GP10): K14←→ K17  (物理行2)
Col9  (GP11): K18←→ K21  (物理行3)
Col10 (GP12): K19←→ K22  (物理行3)
Col11 (GP13): K20←→ K23  (物理行3)
Col12 (GP14): K24←→ K27  (物理行4)
Col13 (GP15): K25←→ K28  (物理行4)
Col14 (GP16): K26←→ K29  (物理行4)
```

### 线性键（6 根，独立 GPIO + 共地）

```
       GND ════════════════════════════════
               ║     ║     ║     ║     ║     ║
             ┌─╨─┐ ┌─╨─┐ ┌─╨─┐ ┌─╨─┐ ┌─╨─┐ ┌─╨─┐
             │Fn1│ │Ctl│ │Alt│ │GUI│ │Sft│ │C+8│
             └─╥─┘ └─╥─┘ └─╥─┘ └─╥─┘ └─╥─┘ └─╥─┘
               ║     ║     ║     ║     ║     ║
             GP17  GP18  GP19  GP20  GP21  GP22
```

## 优势

| 特性 | 5×6 矩阵 | 2×15 矩阵 |
|------|---------|-----------|
| 行线数量 | 5 根 | **2 根** |
| 列线长度 | 穿 5 个键 | **穿 2 个键** |
| 鬼键风险 | 中 | **极低** |
| GPIO 用量 | 11 | 17 |
| 飞线难度 | 中等 | **简单** |

## 编译

```bash
# 复制到 vial-qmk
mkdir -p ~/vial-qmk/keyboards/elf
cp -r elf_2x15_right ~/vial-qmk/keyboards/elf/right
cp -r elf_2x15_left ~/vial-qmk/keyboards/elf/left

# 编译
cd ~/vial-qmk
make elf/right:vial
make elf/left:vial
```

## 刷写

1. 按住 Pico 的 BOOTSEL 按钮
2. 插入 USB
3. 拖入 `.uf2` 文件到 RPI-RP2 U盘
